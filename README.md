# React SPA Portfolio

SPA-проєкт на React, створений для презентації себе як початківця frontend-розробника.

## Можливості проєкту

- React Router маршрутизація
- API-запит погоди
- Компонентна структура
- Адаптивний дизайн
- Сучасний інтерфейс

## Сторінки

### Про мене
Інформація про мене, мої навички та проєкти.

### Моє місто
Опис міста Київ та відображення поточної погоди через API.

### Моє майбутнє
Мої професійні цілі та розвиток у сфері IT.

## Технології

- React
- React Router DOM
- JavaScript
- CSS
- Axios
